# ministrysale.org

Маркетинговий сайт AI-агентів «Міністерства з Продажів».

## Локальний запуск

```bash
npm install
npm run dev
```

Перевірка перед публікацією:

```bash
npm run typecheck
npm run build
```

## Підключення перед запуском

Скопіюйте `.env.example` у `.env.local` та додайте погоджені значення. Сайт навмисно лишається `noindex`, форми не надсилаються, а кнопки тарифів ведуть на демо, доки не виконані умови запуску.

1. Додайте адресу застосунку в `APP_URL` та встановіть `CHECKOUT_MODE=app` після перевірки переходів.
2. Додайте HTTPS-вебхук заявок і постійне сховище для обмеження частоти запитів.
3. Додайте погоджені юридичні тексти та повні реквізити ФОП.
4. Додайте реальні скріншоти кабінету й підтверджені логотипи клієнтів.
5. Додайте GA4 і Clarity. Вони завантажуються тільки після згоди на аналітичні cookie.
6. Після фінальної перевірки встановіть `LEGAL_READY=true` та `SITE_LIVE=true`.

## Структура

- `app` - сторінки, API заявок, SEO-файли та переходи в застосунок.
- `components` - секції, форми, навігація та інтерактивні компоненти.
- `lib/content.ts` - тексти, тарифи й дані сторінок.
- `app/globals.css` - дизайн-система й адаптивна верстка.
